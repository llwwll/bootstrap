轻松上手。

把 Bootstrap 的 CSS 和 JS 快速加进任意项目。可以用你熟悉的包管理器、下载源码，或直接使用 Bootstrap CDN。

用包管理器安装

通过 Bower、Composer、Meteor 或 npm 引入 Bootstrap 的 Sass 和 JavaScript 源文件。包管理器安装不含文档，但包含 Gruntfile 和说明文件。

为所有人、所有场景而设计。

Bootstrap 让前端开发更快、更简单。它适合各种水平的开发者、各种形态的设备，以及各种规模的项目。

预处理器

Bootstrap 提供现成的 CSS，源码则使用流行的 CSS 预处理器 Sass。可以直接用编译好的 CSS，也可以在源码上继续开发。

一套框架，覆盖所有设备。

Bootstrap 用同一套代码，借助 CSS 媒体查询，让网站和应用从手机、平板到桌面都能高效适配。

功能齐全

你将得到详尽的常见 HTML 元素文档、数十个自定义 HTML 和 CSS 组件，以及实用的 jQuery 插件。

Bootstrap 是开源的！它在 GitHub 上由像你一样的人托管、开发和维护。
